# Auto-Lernen

Sprach-Abfrage für Karteikarten, z. B. beim Autofahren: Die Seite liest Fragen vor, hört die Antwort übers Mikro und merkt sich, wann eine Karte wieder fällig ist.

Diese Seite enthält **keine Karten**. Sie werden am Handy aus einer `karten.json` geladen (erzeugt von der Lernzentrale mit `auto_lernen.bat`) und bleiben nur auf dem Gerät.

Online: https://sebastiandobrovolny3009.github.io/auto-lernen/
